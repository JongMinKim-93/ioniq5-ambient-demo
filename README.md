# 아이오닉 5 무드등 미리보기 (데모)

음악에 맞춰 아이오닉 5 실내 무드등(앰비언트 라이트)을 움직이는 개인 프로젝트의 **미리보기 페이지**입니다.
차 헤드유닛에 들어가는 조명 코드를 컴퓨터에서 그대로 돌린 결과를, 차 문짝 모양으로 노래와 함께 보여 줍니다.

**보기**
- 무료 음악(CC BY) 11곡: https://jongminkim-93.github.io/ioniq5-ambient-demo/
- 가요·K-pop 12곡 (소리는 유튜브 영상): https://jongminkim-93.github.io/ioniq5-ambient-demo/youtube/

- 문짝 6개 = 같은 노래를 설정만 바꿔서: 인공지능 DJ (암전 끔 / 암전 강), 무드, 비트, 단색, 커스텀 예시
- 아래 막대 = 곡 전체의 밝기와 색, 누르면 그 위치로 이동
